# 本机 Skills 扫描导入 Review 修复记录

日期：2026-11-03。复核提交：`9528f30 feat(skill-import): add desktop-backed Skills import`。

本记录补充[原开发验收记录](2026-11-03-本机Skills扫描导入开发验收记录.md)，原记录中的测试数量为该次开发的历史结果。

## 发现与修复

| 优先级 | 问题与影响 | 修复与回归覆盖 |
|---|---|---|
| P1 | 事件累计字节预算依赖业务事务成功，非法 JSON、DTO 错误和状态错误请求可绕过累计限制 | JSON parser 的 verify 阶段按实际解压字节独立记账，Redis 原子计数并设置固定 TTL；覆盖畸形、转义、重复请求和无 Content-Length 请求，依赖故障返回 503 |
| P1/P2 | URL 编码的会话 ID 与 Express 解码后的路由不一致，可绕过入口预算匹配 | 统一解码会话段并校验 ASCII ID，入口与 JSON parser 共用匹配；编码与原文使用同一计数键，拒绝编码斜线和重复编码 |
| P2 | 快速切换或超时的预览命令占用轮询前 20 条窗口，已完成命令的迟到错误可能回退状态 | 替换及超时预览时完成旧命令，忽略已完成命令的后续事件；覆盖 22 次快速预览及迟到事件 |
| P2 | 已记住设备复用授权未重新校验最低客户端版本 | challenge 支持当前 clientVersion，兼容回退至当前 pairing 或设备版本，grant 再校验；覆盖升级、不记住设备及最低版本调整 |
| P1/P2 | 10000 文件分页与状态轮询共用 60 次限流，失败后无法恢复 | 按 view 独立限流，files 每分钟 120 次；Web 对临时错误最多重试两次并遵循 Retry-After，增加当前失败页的手动重试 |
| P2 | 分页可能在快照或会话过期、会话终止后继续请求 | 查询、自动翻页及重试同时校验快照、绝对和空闲期限；覆盖迟到响应不再触发下一页 |
| P2 | 成功导入后会话自然过期清空表单已接收的包 | 保留已交付 artifact；显式取消、切换技能、身份变化和撤销授权仍清空，补充回归测试 |
