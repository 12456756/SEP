## 1. 这次交付的边界

已实现企业账号与加密凭证管理、执行与人民币费用关联、结算与划转待办、回执校验、对账记录、权限接口和管理页面。

**这是可测试的本地准备代码。自动远端开户、正式企业 Key 调用、真实人民币费用查询和双边扣款尚未接通。**

生产适配器明确返回“未接通”，不会模拟开户、充值或结算成功。没有提供启用 `ENTERPRISE` 的管理接口。`LEGACY` 和 `PREPARING` 企业继续使用当前调用与扣费流程；即使手动改数据库为 `ENTERPRISE`，已纳入保护的真实执行入口也会拒绝调用，不借用平台 Key 回退。

## 2. 企业账号与三类 Key

- 新增企业算力绑定，保存企业编号、远端账号、唯一开户业务编号、集成模式、开户状态、错误代码和同步时间。
- 注册企业、无归属账号创建企业这两个入口，都在创建企业的同一数据库事务中保存绑定及开户待办；不在事务内请求远端。
- 现有企业可由平台管理员点击“准备企业连接”；重复或并发操作保持一个绑定、一个原开户业务编号。
- 对话、图片、视频三类凭证按企业、用途和版本分开存储。当前版本唯一由企业行锁下的事务切换保证，保留历史版本引用。
- 使用项目现有 AES-256-GCM 工具加密落库。状态接口只查询遮罩和版本，不返回完整 Key、密文或服务认证信息。
- 校验三类凭证齐全，拒绝同版本内容变化、旧版本覆盖、绑定账号变更和过期任务领取者写入。
- 凭证入库后只标记账号就绪，不自动开启新计费。
- 删除企业时清除该企业本地凭证、阻断未完成同步任务，保留新增账务记录。没有执行真实企业删除；远端注销仍待接口及业务规则确认。

## 3. 连接选择与执行关联

新增 `ComputeConnectionService` 和内部凭证选择方法，区分平台连接、企业指定用途凭证，以及原任务固定版本凭证。

已在客户端网关、Web 对话、数字员工、任务规划、任务交付、能力分析、真实图片和视频的新执行入口加入未就绪保护。媒体原结果查询保持原路径，平台参数校验继续使用平台连接。知识库 embeddings 不在本次切换范围。

**现有模型请求当前仍读取原连接配置。企业 Key 选择和固定版本读取已通过测试，但没有接到正式收费调用上。** 正式切换须与远端服务认证、价格来源和账务流程一起实施。

新增执行关联记录可在请求前生成稳定编号，绑定原业务记录、企业账号、凭证编号及版本，后续记录远端请求号、异步任务号和最终账单。原任务查询按当时的凭证版本读取，不因 Key 轮换改用其他账号。

关联记录用于串起现有执行和账单，不替代现有 `ComputeUsageRecord`、媒体资金预占记录或钱包账本。

## 4. 人民币费用、结算和划转

### 实际费用

- 金额固定为 `currency=CNY`、6 位小数字符串，使用 Decimal；不在新模块计算模型价格、倍率或汇率。
- `PENDING` 的金额是未知，保存为 `null`；`FINAL` 的 `0.000000` 才表示真实零费用。
- 同一执行的远端请求号、任务号不能变化；最终账单编号、版本和金额不可被后续回执改写。
- 结算必须匹配同企业、同用途执行上已确认的最终费用。

### 本地结算决定

- 保存总费用、免费覆盖、付费承担和欠费，校验 `gross = free + paid + unpaid`。
- 重复同编号同内容返回原记录，同编号不同内容拒绝；保存本地规范化摘要。
- 没有欠费的决定生成待同步任务；存在欠费时保留 `UNPAID`，不提交“已全额结清”。补收仍待业务规则确定。
- `recordSettlement(tx, ...)` 要求与未来实际扣款使用同一个事务，事务失败时决定及待办一起回滚。

### 钱包转入和退回

- 准备正金额、独立方向、原资金流水引用和幂等划转编号。
- `recordTransfer(tx, ...)` 与原资金变化共用事务；重复原编号不重复建单，更改企业、方向、金额或资金引用则拒绝。
- 当前两个记录方法都只保存记录，**尚未挂接现有真实资金过账路径，不会自行扣钱包或消耗免费额度**。

### 重试与回执

- 待办保存在数据库，不依赖进程内存；定时领取包含租约、领取令牌、重试次数、下次执行时间。
- 开户、结算和划转都有本地处理分支；过期租约可重新领取，旧领取者不能覆盖新的处理结果。
- 结算回执逐项核对企业、账号、业务编号、执行、账单版本及免费/付费金额；划转回执核对企业、账号、编号、方向和金额。
- 回执一致后，原业务记录与待办在同一事务中标记完成并保存远端流水号。
- 超时或回执不匹配保留原操作。测试验证了丢回执后沿用原编号恢复；真实远端查单和幂等行为仍需联调。
- 只保存允许的错误代码和对应安全原因，不持久化可能带有 Key 的原始适配器异常。
- 生产适配器没有 HTTP 实现，所有本次验证均未请求真实模型或远端账务。

## 5. 对账

新增对账快照，保存原对账编号、游标、两边流水水位、人民币余额和差异。

只有水位一致才比较余额；水位不同则拒绝。金额相同才能推进已核对游标，旧水位不能回退游标。差异只记录，不自动补扣、充值或改任一方余额。未获取远端快照时显示“尚未核对”，不展示虚构的零余额。

当前提供内部快照校验和持久化方法，尚未从 N08/N09 自动拉取余额与流水。

## 6. 页面与接口

平台入口：`/admin/compute-integrations`；企业设置入口：`/settings/compute-connection`。

平台页支持企业搜索、分页、详情、准备连接，查看开户、执行费用、结算、划转、对账记录；记录支持业务编号和状态筛选，每类返回最近 50 条。远端未接通时禁用原操作重试。企业管理员仅查看本企业状态，普通成员不能查询；企业缓存按企业身份区分。

所有路径以下列 `/api` 为前缀：

| 方法 | 路径 | 权限与作用 |
|---|---|---|
| GET | `/admin/compute-integrations` | 平台管理员，企业分页搜索 |
| GET | `/admin/compute-integrations/:enterpriseId` | 平台管理员，安全状态详情 |
| GET | `/admin/compute-integrations/:enterpriseId/records` | 平台管理员，按 `keyword/status` 筛选记录 |
| POST | `/admin/compute-integrations/:enterpriseId/prepare` | 平台管理员，保存准备记录，不启用新模式 |
| POST | `/admin/compute-integrations/jobs/:jobId/retry` | 平台管理员，恢复原操作；未接通返回 503 |
| GET | `/enterprise/compute-integration` | 企业管理员，从登录成员关系确定企业 |

接口使用 JWT、平台角色或企业管理员检查、共享 Zod 校验和 Swagger。没有开放客户端提交免费金额、任意改远端余额、完整 Key 读取或强制同步成功接口。

1. 算力平台完成并冻结 N01/N02、N04–N09，以及原模型请求的服务认证、执行编号、人民币报价/实际费用和免自动全额扣款规则。

企业删除后的远端账务收尾、欠费补收、个人钱包资金归属仍按原方案列为待确认事项。新增本地账务证据独立保留；面向已删除企业的专门审计查询不在当前页面范围。
