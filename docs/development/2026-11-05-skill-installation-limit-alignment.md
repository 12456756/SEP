## 问题与变更

客户端提交 `dd45adb`、`24e9139`、`d009e13` 已取消员工运行时技能安装的大小和文件数限制。SEP 后端仍在安装产物准备与描述符 schema 中使用 20MiB、500 文件上限，导致可上传并审核的技能在员工上架时返回 `INVALID_ENTRY`。

本次移除上述后端安装限制及 `CLIENT_ARTIFACT_LIMIT` 提示。协议版本仍为 1，`byteLength`、`fileCount` 与当前客户端一致，只要求正的 JavaScript 安全整数。包哈希、批准正文一致性、路径安全、授权与版本状态检查继续生效。

上传和解包通道的资源预算继续保留：压缩包 100MiB、总条目 10,000、解压后 500MiB、入口及正文 2MiB。这些预算与安装描述符的校验分开，不再额外按 20MiB、500 文件拒绝已验证包。

客户端同步取消归档父目录必须等于技能名、多份 `SKILL.md` 必须拒绝的限制。保留包内所有文件，只加载描述符指定入口；路径碰撞、哈希、批准正文和缓存完整性检查继续生效。每次产物下载超时从 30 秒延长为 10 分钟，保留取消与限流重试。
