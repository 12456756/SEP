# 企业模型调用停用公共 Key

日期：2026-11-24。范围：SEP 后端和前端企业算力连接页面。算力平台代码未修改，无数据库结构变更或迁移。

后续修订：开户成功后自动接通，不再需要手动启用。以下涉及手动启用的描述和验证结果为上一轮交付记录；当前行为及本轮验证见 `sep-compute-automatic-connection-2026-11-24.md`。

## 业务规则

- 企业对话、任务规划、任务执行、汇总、能力分析、图片和视频执行使用本企业对应用途凭证。
- 未开户、未启用企业独立连接、远端未就绪、凭证缺失或初始资金未同步时明确拒绝调用，不回退管理员 Key。
- 模型目录仍可在开户凭证就绪后、正式启用前读取，方便检查企业可用模型；这不代表已允许生成。
- 图片、视频新报价必须绑定企业凭证。新图片执行不再使用平台连接快照，人民币价格由算力返回，不再使用 SEP 汇率计算新单。
- 已有企业媒体任务继续使用其冻结的企业凭证查询。没有企业凭证的旧任务不得改用管理员凭证，保留原任务及待核对账务；已缓存且已结清的结果仍按原授权检查访问。明确未发送的任务可按既有流程释放预占，未知执行不据此退款。
- 管理员图片、视频报价校验及明确的后台模型管理操作仍使用管理员账号凭证，与企业执行解析分开。知识库既有部署级嵌入服务不在本次对话/图片/视频企业凭证改造范围内。

## 后端改动

- `compute-integration.service.ts`：`assertEnterpriseReady()` 拦截非企业独立模式，保留连接状态及初始资金同步检查。
- `compute-connection.service.ts`：`chatProvider()` 不再因旧模式返回空值；企业解析通过强制检查后再选择用途凭证。
- `compute-media.service.ts`：新媒体连接不再返回空值触发平台连接回退，历史执行继续固定原凭证。
- `sub2api-provider-config.ts`：企业解析缺少企业上下文或解析器时直接拒绝；管理员操作改为显式的 `resolveAdminSub2ApiProviderConfig()`。
- `gateway.service.ts`：连接只能从企业解析器获得，不再读取平台公共 Key。
- `media-real.service.ts`、`media-real.guard.ts`、`media-video-real.service.ts`：入口强制企业连接，新报价、发送和恢复不使用管理员连接。
- `employee-copy-draft.service.ts`：后台文案生成显式使用管理员解析函数，不能成为企业调用的隐式回退。
- `shared/compute-integration.dto.ts`：补充未启用、缺少上下文、连接不可用及初始资金未同步的错误提示。

## 前端改动

- 不再显示“原平台连接”；历史内部 `LEGACY` 枚举仅为兼容现有数据保留，页面显示“未启用”。`PREPARING` 显示“待启用”，明确开户凭证就绪不等于执行已启用。
- 企业端连接页说明当前阻塞原因；平台端保留开户、重试原操作，并增加“启用企业连接”。启用失败显示后端具体原因。
- 启用仍受后端账务保护：原任务和旧账需清理，停止对话至少 10 分钟，远端空账本，三类凭证齐备；符合条件才允许切换和同步初始余额。前端按钮可点击不代表服务端账务检查必然通过。
- 后台统一 Key 配置标题改为“管理员模型连接”，明确用途为平台管理。企业成员不从该配置获得执行凭证。
