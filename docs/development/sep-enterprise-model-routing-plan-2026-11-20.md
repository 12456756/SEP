# 企业模型目录与管理员媒体配置调整

日期：2026-11-20。按用户最新要求实施：企业模型目录、调用凭证归属企业；图片和视频 Profile 仍由平台管理员维护，其管理员账号 Key 用于目录发现与报价校验。

本批开发步骤：

1. 增加只读企业连接及模型目录服务，按可信企业身份和 chat/image/video 用途读取 Key。目录异常、缺失凭证及部分响应明确失败，不回退管理员目录，不返回 Key。
2. 企业模型偏好及保存、部门策略、有效模型范围改为使用企业对话目录。平台元数据仅作展示或显式禁用，不扩大企业权限，不展示旧公共 Key 倍率或 SEP 估算价格。
3. 企业图片/视频可选 Profile 及策略保存检查企业相应用途 Key 的模型权限；管理员 Profile 创建、编辑、发现、报价验证继续走管理员连接。运行配置区分参数已验证、企业有权限、结算尚未接通。
4. 补齐跨企业/用途隔离、管理员 Key 分工、缺失/失效/部分目录、保存和运行配置测试；验证前后端类型及实际页面。

本批不启用真实新结算，不用“换 Key”替代免费免扣及双边账务联调；现有资金路径、旧在途任务的处理规则保持原状。开发完成后在交付文档中明确各路径的实际状态。
