# 企业永久删除

## 范围与交互

平台管理员可从企业列表或详情页发起永久删除。先加载删除预览，显示钱包余额、冻结金额、算力专款、成员、订阅、知识库、任务与待支付订单。资金和业务状态只提示，不作为拒绝删除的条件；管理员输入完整企业名称确认。删除不会自动退款。

删除企业组织、企业钱包及流水、订单、订阅、知识库、企业任务、企业配置、API Key、归属明确的对话和企业专属文件。保留成员个人账号、个人钱包和个人充值订单。已进入平台共享或其他企业引用的能力/版本保留为独立平台资产，企业私有内容清除。保留平台操作审计和删除任务摘要。

## 接口

- `GET /admin/enterprises/:id/deletion-preview`：删除影响预览。
- `GET /admin/enterprises/:id/deletion`：恢复已有删除任务。
- `POST /admin/enterprises/:id/deletion`：提交 `{ confirmName }`，返回持久化任务。
- `GET /admin/enterprise-deletions/:jobId`：查询进度。
- `POST /admin/enterprise-deletions/:jobId/retry`：重试失败任务。

以上接口均使用 JWT 与平台 ADMIN 权限检查。请求通过共享 Zod schema 校验。

## 执行与一致性

`EnterpriseDeletionJob` 不引用企业外键，保留快照、清理清单、阶段、尝试次数和执行租约。状态为 `PENDING/RUNNING/FAILED/COMPLETED`，阶段为 `PREPARE/DATABASE/FILES/DONE`。后台定时扫描待执行或租约过期任务，多实例使用原子认领，重启后继续执行。失败显示错误并允许重试。

1. 持久化任务并生成资源清单；校验企业名称后关闭企业、撤销成员现有认证会话，并请求运行中任务在当前步骤结束后停止。关闭后新支付回调和业务请求不能继续履约。
2. 等待运行任务收敛，释放未结算媒体预留款，再按清单删除企业上传目录及知识库原件；仅清理没有其他引用的内容寻址包与知识库原件。失败时企业仍保留为关闭状态，管理员可从详情页重试。
3. 文件清理成功后，在单个数据库事务中清除显式企业归属的独立表及关联数据，解除共享平台资产归属，最后删除企业并写入平台审计。该事务成功后任务进入 DONE；数据库失败可安全重试文件幂等清理和数据库事务。

不得对 Redis 使用全库清空，不得删除共享员工模板或其他企业数据。不得把余额提示当作业务前置条件。

## 历史归属

新对话写入不可变的 `ConversationSession.enterpriseId`。历史对话以账单 `sessionId` 和任务步骤关联为依据；无这些证据时，只有单一企业成员且会话创建不早于该成员加入时间才归属本企业。无法确定归属的历史记录不按 userId 全删。企业级物理归属在后续所有写入中继续固定。

## 验证

覆盖有余额仍可提交、名称不符、权限限制、重复提交、跨企业隔离、个人钱包保留、平台共享版本保留、数据库失败回滚、文件失败重试、租约恢复与完成状态。前端覆盖确认、警告、进度和重试。运行定向 Jest/Vitest、类型检查与构建；使用临时测试企业进行端到端验证，不删除已有企业。
