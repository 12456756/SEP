## 混合结算

算力平台的结算回执 `sequence` 表示本次结算最后一条流水的序号。SEP 按以下规则核对通知：

| 结算方式 | 付费流水 | 免费流水 |
| --- | --- | --- |
| 全付费 | 回执序号 | 无 |
| 全免费 | 无 | 回执序号 |
| 免费与付费混合 | 回执序号减 1 | 回执序号 |

保留企业、原执行、原结算编号、付费流水编号、金额及本地已结算状态的校验。通知仅确认已有结算，不再执行扣费。

历史卡住的通知可用原事件重新同步，不需要重新生成模型任务、重新结算或人工修改流水水位。
