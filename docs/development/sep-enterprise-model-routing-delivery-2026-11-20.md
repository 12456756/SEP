# 企业模型目录与管理员媒体校验交付说明

日期：2026-11-20。本文是第一批算力集成本地准备代码之后的增量说明。

后续更新：签名、JWE、控制接口及本机跨平台联调已继续实现，以 `sep-compute-v1-review-and-local-integration-2026-11-20.md` 为最新状态。本文中“远端适配器尚未接通”是这一批交付时的状态，不再代表最新代码；完整业务资金链路仍未启用。

## 已完成的功能

### 1. 模型偏好读取企业自己的模型

企业可用模型通过本企业 `chat` Key 查询算力平台 `/v1/models`。企业 A、企业 B，以及图片、视频三个用途分别取对应凭证，没有共享目录缓存。不会在企业 Key 缺失、失效或返回空列表时改用管理员 Key。

平台模型表只补充供应商、上下文和能力等展示信息，并保留显式禁用限制；管理员目录没有的企业模型也能出现。已知的图片、视频、embedding 模型不会进入会话候选列表。算力目录若只返回模型编号，未知模型的对话能力仍由对话 Key 的上游授权保证，SEP 不凭模型名称猜测能力。

会话默认、员工指定模型、编排模型、企业白名单、部门模型策略在保存时检查企业对话 Key 的可用范围。调用侧要求实际可用集合时，再取当前目录与企业、部门策略交集。员工模板中无权使用的模型不能绕过这个交集。

编排模型留空现在跟随企业默认会话模型；企业首次配置时优先采用企业目录内的平台建议默认，否则取企业目录中的第一个模型。企业目录为空时明确报错，不保存一个企业无权使用的默认值。

企业模型列表不再展示旧公共 Key 的倍率、本地估算单价或把缺少费用数据当作免费。价格仍待算力平台既有信息及实际费用接口提供；本批没有新增价格目录或改价入口。

### 2. 图片、视频规格仍由平台管理员维护

平台继续创建、编辑、校验和启用图片、视频 Profile。企业可选择的范围为：平台已启用且已校验的 Profile，与企业相应用途 Key 的模型目录交集。

企业新增授权或变更默认 Profile 时，后端校验自己的 Key 是否拥有该模型。历史已选但当前不可用的配置会在页面提示；企业仍可以移除这些授权，不要求先修复远端 Key。原封保留历史授权不代表可以执行，执行能力仍复核当前权限。

参数规格的配置权限没有交给企业，也没有拿管理员报价结果代替某企业最终费用。

### 3. 管理员账号 Key 用于报价校验

| 场景 | 使用凭证 | 地址与配置 |
| --- | --- | --- |
| 企业会话/员工/编排模型目录 | 该企业 `chat` Key | `SUB2API_BASE_URL`；不读取公共 `SUB2API_API_KEY` |
| 企业图片候选配置过滤 | 该企业 `image` Key | `MEDIA_BASE_URL`；不读取管理员图片 Key |
| 企业视频候选配置过滤 | 该企业 `video` Key | `MEDIA_VIDEO_BASE_URL`；不读取管理员视频 Key |
| 平台图片模型发现及参数报价校验 | 管理员算力账号图片 Key | 原图片连接 `MEDIA_BASE_URL` / `MEDIA_API_KEY` |
| 平台视频模型发现及参数报价校验 | 管理员算力账号视频 Key | 原视频连接 `MEDIA_VIDEO_BASE_URL` / `MEDIA_VIDEO_API_KEY` |

管理员页面入口：系统设置 → 模型管理 → 图片/视频，字段已标为“管理员校验 API Key”。沿用已有后台加密保存方式，页面不回显明文 Key，不需要给本功能另建一种认证。后台只能验证凭证是否可用，凭证所属账号仍需管理员正确配置。

图片参数校验固定同一份管理员连接快照，发现模型和所有报价检查都使用这份快照；校验期间管理员连接被更换则要求重新校验。视频原流程也固定管理员适配器连接进行目录和报价请求。相关测试确认两者均不查询企业凭证。

校验只调用目录和报价接口，不发送真实生成任务，也不扣生成费用。现有报价适配器仍遵守旧报价响应协议；新人民币费用契约接通后再切换真实执行和结算。

### 4. 页面和错误状态

模型偏好展示失效的已选模型，编排选项改为“跟随企业默认”；保存成功后按服务器配置重置表单。目录查询失败显示后端原因。图片、视频分别提示本企业 Key 未就绪。

V3 媒体能力和授权预览区分企业模型无权限与结算未接通：`ENTERPRISE_MODEL_UNAVAILABLE` / `SETTLEMENT_NOT_CONNECTED`，预览对应 `enterprise-model-unavailable` / `settlement-not-connected`。凭证和目录错误继续使用既有错误诊断及脱敏链路。

## 当前不能当作完成的部分

这次完成的是目录、配置、权限及管理员报价凭证的切换，**不是所有实际生成和扣费已切换企业 Key**。

- 算力平台注册企业、交付三个真实 Key 的远端适配器仍未接通，准备操作不会伪造开户成功，也没有新增人工粘贴企业 Key 的公开接口。
- 真实对话执行仍保留旧模式调用和扣费路径；`ENTERPRISE` 模式继续明确拒绝新执行。没有将换 Key 当作完成免费免扣和新计费。
- 当前媒体运行配置不会发布可执行生成工具；有企业 Key 且有模型权限时，也会因为人民币结算未接通而返回不可执行。缺少企业 Key 时为连接未就绪。**因此整个工作树不能作为“现有媒体生成完全不受影响”的版本直接部署。**
- 原视频任务查询和下载仍沿用已有授权及恢复流程；本批没有迁移旧任务凭证，也没有把在途任务改成新企业结算。
- 免费额度授权、人民币实际费用、充值/退回同步、双方结算和跨平台失败恢复仍需算力平台接口实现并联调。旧对话价格及扣费代码没有在本批删除。
- 管理员 Key 仅用于配置校验，不赋予开户、充值、批准免费结算权限；这些仍需要独立 SEP 服务认证。

本批未修改 Prisma schema，也未新增迁移；工作树中已有的两次迁移属于上一批准备代码，整体发布仍需执行。本批没有增加依赖。
