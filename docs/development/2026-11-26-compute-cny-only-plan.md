# SEP 仅采用算力平台人民币费用

## 原则与范围

SEP 不维护模型价格、汇率或保底价。新请求的报价、最终费用来自算力平台，SEP 只负责付款来源分摊、记账、同步和对账。未知费用不能视为零，也不能根据 Token 或美元字段推算。

1. 关闭旧模型计价快照及本地换算入口。历史未结清任务缺少算力最终费用时保留待核对，不能重新生成或猜价扣费。
2. 后台图片、视频 Profile 校验使用算力 `/api/v1/sep/validation/{kind}/pricing` 的人民币合同，不使用管理员普通 USD 报价。
3. 媒体提交、生成、文件、财务状态独立保留。上游附带的美元诊断字段不能成为回执成功与否或扣费金额的依据；最终费用仍须取得企业执行的人民币费用单。
4. 下线汇率及保底单价设置、平台模型的本地价格声明。保留历史数据库字段和历史金额，不执行数据库迁移。
5. 不修改 sep-client 或算力平台源码；对外响应的必要兼容字段可以为空，不伪造美元金额。

## 验证

- 人民币最终费用为唯一结算来源；缺失、未最终确认、归属不符的费用拒绝结算。
- 纯人民币后台报价可校验，USD 报价不能进入企业结算。
- 媒体回执没有美元字段仍可解析；错误、原任务编号、提交未知恢复与幂等扣费规则保留。
- 重点运行模型、对话、网关、图片、视频、企业账务及设置测试，完成前后端类型检查。
- 不调用付费生成，不部署、不提交、不推送。

## 已实现的行为

| 场景 | 当前行为 |
| --- | --- |
| 会话模型扣费 | 必须关联算力执行记录，使用已确认的 `grossCny`；Token 只记用量 |
| 图片、视频报价 | 只接受算力平台 `CNY` 报价；保留企业、模型、规格、报价编号与有效期核对 |
| 后台 Profile 校验 | 使用服务签名访问 `/api/v1/sep/validation/image/pricing` 或 `/api/v1/sep/validation/video/pricing`，不触发生成 |
| 图片、视频结算 | 只使用原执行的最终人民币费用单，继续处理预留款、多退少补核对和付款来源分摊 |
| 算力费用尚未确认 | 保留待核对，不按美元、汇率、Token 或本地免费标记扣费 |
| 旧任务只有本地价格快照 | 保留原任务和历史金额，转待核对，禁止重新估价补扣 |
| 后台汇率、保底单价、活动免费 | 停止提供设置；模型免费与否同样以算力平台最终费用为准 |

### 接口与历史数据

- 新媒体执行回执使用 `execution.billing.actualCostCny`。未知时为 `null`，不得理解为免费；最终入账金额以算力执行费用单和本地账本为准。
- 为读取历史数据保留可空的 `amountUsd`、`usdToCnyRate`、`actualCostUsd` 等字段，新报价和新账单不填写美元金额或换算汇率。
- 上游附带的 `amount_usd` 不参与金额计算或报价有效性判断。原始错误、请求编号、任务编号、生成状态和下载状态继续保留。
- 仍保留少量旧方法签名，但本地计价和直接美元结算方法会明确拒绝调用；旧美元用量查询没有生产调用方，不能用于扣费。
- 旧客户端若强制要求非空美元报价，必须改为读取 `amountCny`，不能由 SEP 补一个虚构美元金额。本次未修改客户端仓库。

### 可识别的拒绝结果

- `COMPUTE_FINAL_FEE_REQUIRED`：缺少算力结算连接或试图使用本地计价。
- `PRICE_UNAVAILABLE`：人民币报价缺失、币种不符、过期、规格或归属不符。
- `BILLING_PENDING`：媒体原执行的最终费用尚未确认，继续查询原任务。
- `IDEMPOTENCY_CONFLICT`：原预留款或执行费用关联冲突，不进行重复扣费。

其他原有资金不足、付款方式变化、账号停用及上游异常回执继续按原流程处理。

## 视频最终费用独立查询补充

- 视频回执的 `execution.billing.status` 仍为 `pending` 时，SEP 也会查询原执行的最终人民币费用单。
- 查询视频状态失败、回执格式无效或返回 `unobserved` 时，保留原错误与已知任务状态，仍独立尝试最终费用查询。
- 一次恢复流程只执行一次费用查询；已完成本地结算时不重复扣款或释放。零元最终账单也明确返回 `actualCostCny: "0.000000"`。
- 未确认费用、账单查询失败或结算失败继续保留预占；后续客户端查询或现有后台恢复任务会重试，只查询原任务，不重新发送生成请求。
- 后台恢复沿用现有每 6 小时运行的任务及分页、并发和租约限制，本次未调整执行频率。
- 本次只修改 SEP 的视频服务和回归测试，未修改算力平台仓库。真实上下游联调仍需等算力平台改动完成。
- 验证：新增 4 项回归先复现旧逻辑失败；修复后视频服务、HTTP、账务、后台恢复及费用关联等 164 项通过，补充 V1/V3、异步任务及恢复租约兼容检查 64 项通过、3 项条件测试跳过。后端 TypeScript 检查通过，相关文件 ESLint 无错误（保留 1 项原有警告），差异格式检查通过。
