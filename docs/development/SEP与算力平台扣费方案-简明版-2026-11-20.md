# SEP 与算力平台扣费方案：简明版

日期：2026-11-20。本文供确认业务流程，功能尚未开发。

## 1. 两个平台各做什么

**算力平台负责算钱、换成人民币；SEP 负责决定免费额度抵多少、付费余额扣多少。**

| 事情 | 负责方 |
|---|---|
| 模型价格、倍率、图片和视频规格价格 | 算力平台管理，SEP 不改价 |
| 本次调用实际多少钱、美元转人民币 | 算力平台计算，直接给 SEP 人民币金额 |
| 免费额度、企业余额、成员使用限制 | SEP 管理 |
| 实际扣款、充值和退回 | 两个平台按同一笔记录同步处理 |

SEP 不再使用自己的模型价格表计算费用，也不再自行乘汇率。不新增独立价格查询接口。

## 2. 企业注册后

企业在 SEP 注册 → 算力平台创建对应账号 → 创建对话、图片、视频三个 Key → 加密交给 SEP 保存并绑定企业。

三个 Key 共用该企业的一份付费余额。员工照常使用客户端，由 SEP 自动选择对应 Key，员工不用填写或查看 Key。

## 3. 对话怎么扣钱

**保留先使用、后结算的方式，不提前冻结免费额度或资金，也不新增执行前估价。**

1. SEP 检查权限、免费额度和可用余额，创建本次请求记录。
2. 使用企业的对话 Key 请求模型，把回答返回给用户。
3. 算力平台确认本次实际费用，并直接返回人民币金额。
4. SEP 后台按结算时的可用额度，先抵免费部分，再扣付费资金。
5. 将确认的免费和付费金额通知算力平台；算力平台只扣付费部分，双方保存结果。

例：本次实际费用 10 元，结算时还有 3 元免费额度。SEP 消耗免费额度 3 元、扣付费余额 7 元；算力平台对应账号只扣 7 元。

免费额度能覆盖全部费用时，两边付费余额都不扣。算力平台不能先自动扣全额，再等 SEP 申请退免费部分。

## 4. 图片和视频怎么扣钱

保留现有流程：先报价 → 暂时占住对应免费额度和资金 → 提交生成 → 确认实际费用 → 结算并退回多占的部分。

报价和实际费用都由算力平台提供人民币金额。免费与付费的处理原则和对话相同。

图片、视频的模型权限、参数和默认值仍在 SEP 配置，参数报价校验使用平台专用凭证；员工实际生成使用自己企业的 Key。

## 5. 充值和退回

| 操作 | 两边的变化 |
|---|---|
| 企业从钱包划入 100 元算力资金 | SEP 划入 100 元，算力账号对应增加 100 元人民币权益 |
| 从算力资金退回钱包 20 元 | 算力账号确认减少 20 元后，SEP 才恢复 20 元钱包可用余额 |
| 将已有企业算力资金分配给成员 | 只调整内部归属，不再次给算力账号充值 |

免费额度不能退回钱包。算力平台内部如何换美元由它处理，SEP 只核对人民币金额和流水。

## 6. 多人同时使用、断网或失败怎么办

请求可以同时执行；后台修改同一份免费额度和余额时，需要数据库保护，不能重复使用或重复扣款。

每次执行、扣费和划转都有唯一编号。断网先查询原记录；重复通知只处理一次，不能重新生成任务或再次充值、扣款。

两边更新可能有时间差，一边成功、另一边失败时显示处理中并继续同步，不直接宣布完成或贸然退款。

**对话不提前冻结资金，所以并发使用后可能钱不够，仍按当前方式记录欠费。** 欠费不算已付款，算力平台不能先扣掉 SEP 尚未收取的部分。

## 7. 开发先后顺序

1. 双方先确认开户、实际人民币费用、免费与付费拆分、扣款确认、充值退回和查询原单的接口。
2. 算力平台实现费用计算、人民币返回及按 SEP 确认金额扣款；SEP 实现企业 Key 绑定和账务同步。
3. 联调全免费、部分免费、多人并发、余额不足、断网重试、视频长任务等情况，再安排切换。

还需明确两件事：对话欠费后如何补收；个人钱包替员工支付时，资金怎样和企业账号隔离。这两项目前不当作已定规则。
