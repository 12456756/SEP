# 企业开户后自动接通算力

日期：2026-11-24。范围：SEP 后端及前端。算力平台无需修改，本次不新增数据库迁移。

## 当前流程

1. 企业注册事务保存固定编号的开户任务。
2. 后台任务调用算力平台开户，将账号及三个用途 Key 加密保存。
3. 保存成功后立即自动完成企业连接初始化，无需管理员确认。
4. 后台每分钟补查已取得凭证但未初始化的企业，自动恢复历史遗漏或中断。
5. 新企业无初始付费资金时直接可用；旧企业已有资金时，沿用固定编号生成一次初始划转，同步完成后可调用。

开户失败与连接初始化失败分开保存。已保存的开户成功结果不会因初始化失败而重置或再次开户。初始化失败记录脱敏后的具体原因，后台自动重试。

## 保护与兼容

- 保留企业行锁、企业状态、三用途凭证齐备、旧任务与账务检查。
- 初始划转与模式变更在同一本地事务内，重复及并发执行不会重复导入余额。
- 本地有待导入资金时，远端必须无流水，避免重复导入；本地无待导入资金时，允许已有算力侧充值流水，由既有余额同步流程处理。
- 保留初始资金未同步前的调用拦截，不回退公共 Key。
- 内部 mode 字段保留用于历史账务兼容，不再作为管理员可设置的开关。
- 删除 POST `/admin/compute-integrations/:enterpriseId/activate`，删除响应中的 `activationAllowed` 和前端手动启用操作。
- 页面保留实际开户状态、凭证遮罩及异常。开户中和初始化中每 5 秒更新状态，完成后显示“已开通”。
